# -Big-Data-Projects
Project 1: Taxi Trip Data Analysis using MapReduce
Built scalable MapReduce jobs to analyze NYC taxi trip data stored in HDFS.
Implemented in-mapper combining to compute statistics such as trip distance, fare maxima/minima, and averages.
Designed a custom PAM clustering algorithm to group drop-off locations and uncover spatial trip patterns.
Created a multi-stage MapReduce pipeline for dataset joins, trip aggregation, and company ranking.
Focused on memory efficiency and fully distributed processing on AWS EMR.
